# Features

## Items
- Add an item (name, description, site: Depop or Vinted)
- Cost field, defaults to $0 (current stock is free storage stock)
- Status: not photographed, photographed, listed, sold
- Photo checklist per item: tag, front, back, sleeves, care instructions

## Sales and profit
- When sold: enter sale price, fees, shipping
- See profit per item and total profit

## Goals
- Add a goal with a name and dollar amount (printer $89, mannequin, kitchen island $200)
- Available balance = total profit minus money already spent on goals
- Progress bar for each goal
- Mark a goal as purchased
